# 2026-08-19 工作日志

## 为 ur_sport_record 表生成 CRUD 接口（oh-urban 模块）

依据 `db/mysql/oh-boot.sql` 中 `ur_sport_record`（运动记录表）结构，在 `oh-module/oh-urban` 模块按项目规范生成增删查改代码，参照同模块 Trajectory/Event 的写法。

表字段：id、user_id、record_date(varchar yyyymmdd)、start_time、end_time、duration(秒)、remark + 审计字段(db_status/creator/create_time/updater/update_time)。

新增文件（com.finn.urban 包下）：
- entity/SportRecordEntity.java（@TableName("ur_sport_record")，extends BaseEntity，字段 userId/recordDate/startTime/endTime/duration/remark）
- vo/SportRecordVO.java（Serializable）
- query/SportRecordQuery.java（extends Query；userId/recordDate/startDate/endDate/keyWord）
- mapper/SportRecordMapper.java（extends BaseMapper<SportRecordEntity>）
- resources/mapper/postgres/SportRecordMapper.xml（空 mapper）
- convert/SportRecordConvert.java（MapStruct @Mapper + INSTANCE）
- service/SportRecordService.java（page/detail/save/update/delete）
- service/impl/SportRecordServiceImpl.java（QueryWrapper/UpdateWrapper 风格，save 强制写入当前登录用户 userId + 审计字段，delete 逻辑删除 db_status=0）
- controller/SportRecordController.java（@RequestMapping("/sportRecord")，权限 `urban:sport-record:{page|info|save|update|delete}`，@Log 操作日志）

约定确认：
- URL 多词用 camelCase（参考 /sys/errorLog、/sys/openUser）；权限串用 kebab-case（参考 urban:trajectory:page）。
- 项目缺 oh-framework 1.0.1_260718 私有制品（本地仅有 4.2.x，其 common 类在 com.finn.framework.common 下，与项目 com.finn.common.* 不匹配）。曾用 4.2.4+common 合并构造临时 jar 做编译验证，通过框架/公共类的全部解析，唯一残留报错为 @Log.type 枚举签名差异，且同时出现在已有 Event/Trajectory 代码上 → 属环境版本差异，非本次代码问题；验证后已清理临时制品，未改项目文件。
